Day 13: Hoisting and TDZ

Lesson: Topics and demo code (check the console)

Execution context, hoisting, TDZ, and the call stack

Open DevTools Console to see the live demos from lesson.js. The panels below mirror the same ideas as readable snippets.

Topic 1: Global vs function execution context and var

Global bindings live in the script’s outer execution context. Each function call gets its own function context (parameters, locals). var is function-scoped and hoisted with an initial value of undefined.

Topic 2: Creation vs execution phase, let/const, and the TDZ

Think of two phases: create bindings, then run statements top to bottom. let and const are in the temporal dead zone (TDZ) until their declaration line runs; reading them earlier throws ReferenceError.

Topic 3: Call stack, declarations vs expressions

Nested calls build a call stack: each call pushes a frame; returning pops it. Function declarations hoist differently from expressions stored in var or let/const.
