Day 13: Hoisting and TDZ

Hands-on: In-class tasks (use the console)

Hands-on tasks

Open DevTools Console. Implementations and comments live in day-13/js/hands-on.js. For tasks that would stop the whole file, this runner uses try/catch where noted; copy the exact snippets below into a fresh file when the brief asks you to.

Task 1: Predict the var hoist

What to do: In a fresh JS file, type this exact snippet. Before running, predict each console.log. Run it and compare. Explain why the first log is undefined and not a ReferenceError (see comments in hands-on.js).

console.log(name);
var name = "Priya";
console.log(name);

Task 2: Trigger the TDZ

What to do: In a fresh file, run console.log(city); let city = "Jaipur";. Predict, then run. Write down the exact error name and message (V8/Chrome/Node example: ReferenceError: Cannot access 'city' before initialization). Move let city = "Jaipur"; above the console.log and confirm the file runs. In a comment, spell out what TDZ stands for.

// Broken (for prediction / one-off run):
console.log(city);
let city = "Jaipur";

// Fixed:
let city = "Jaipur";
console.log(city);

Task 3: Function declaration vs expression

What to do: In one file, add these four lines in this order: sayHi(); then greet(); then function sayHi() { console.log("Hi"); } then var greet = function () { console.log("Hello"); };. Predict which call works and which throws. Run and note the exact error type for the failing call. Comment on how hoisting differs between declarations and var function expressions.

sayHi();
greet();
function sayHi() { console.log("Hi"); }
var greet = function () { console.log("Hello"); };

hands-on.js wraps the failing greet() in try/catch so Task 4 still runs in the same page load.

Bonus: Trace the call stack

What to do: Define multiply(a, b) (returns a * b), square(n) (returns multiply(n, n)), printSquare(n) (logs square(n)). Call printSquare(5). In a comment, draw the call stack at the moment multiply(5, 5) is on top (four frames). Predict the final log. Add console.trace() inside multiply and compare DevTools’ stack to your sketch.

function multiply(a, b) {
  console.trace();
  return a * b;
}
