Day 13: Hoisting and TDZ

Homework: Take-home practice

Homework exercises

Use the console and your notes. Starter code and expected reasoning are in day-13/js/homework.js.

Exercise 1: typeof and a hoisted var

What to do: Predict the output of console.log(typeof age); var age = 25; before running. Then run it and compare. Why is typeof on a variable you have not “assigned yet” not a ReferenceError?

console.log(typeof age);
var age = 25;

Answer: The console prints the string "undefined" (not the value undefined without quotes — typeof always returns a string). var age is hoisted, so at the time of typeof age the binding already exists with value undefined. That is a legal read, so you get typeof undefined which is "undefined", not a ReferenceError (which would happen for a non-existent binding or for a let/const in the TDZ).

Exercise 2: Screenshot the TDZ error

What to do: With a let declaration, try to read it on the line above its declaration. Capture a screenshot of the exact error message your console shows (name + message).

console.log(secret);
let secret = 42;

Expected answer (V8 / Chrome / Node): ReferenceError: Cannot access 'secret' before initialization. Your screenshot should show that name and message (wording may vary slightly in other engines).

Exercise 3: Three shapes of the same function

What to do: Write the same simple function three ways: a function declaration, a var function expression, and a const arrow. In each case, try calling it before its defining line. Document which call works, which throws TypeError, which throws ReferenceError, and why.

Use a fresh file for each block below so one error does not stop the rest.

// 1) Function declaration — call before the line
console.log(declaredHi());
function declaredHi() {
  return "Hi";
}

// 2) var + function expression — call before the line
console.log(varHi());
var varHi = function () {
  return "Hi";
};

// 3) const + arrow — call before the line
console.log(constHi());
const constHi = () => "Hi";
