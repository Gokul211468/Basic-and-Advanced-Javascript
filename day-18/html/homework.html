Exercise 1: Sequential Promise Delays

What to do: Write wait(ms) that returns a Promise resolving after ms. Use it: wait(500).then(() => wait(500)).then(() => console.log("1s")).

function wait(ms) {
    return new Promise((resolve) => {
      setTimeout(resolve, ms);
    });
  }
  
  // Wait 500ms twice (sequential)
  wait(500)
    .then(() => wait(500))
    .then(() => console.log("1s"));
  
  /*
  After ~1 second total:
  1s
  
  Key concepts:
  1. Promise constructor with setTimeout for delays
  2. Chain promises for sequential timing
  3. Each .then waits for previous promise to complete
  4. Total time = sum of sequential delays (500 + 500 = 1000ms)
  */

Exercise 2: Promise Chain with Random Failures

What to do: Take a fetchData(id) that randomly succeeds or rejects (50/50). Chain three sequential .thens and end with .catch. Run multiple times to see both paths.

// Fake API function
function fetchData(id) {
    return new Promise((resolve, reject) => {
      // Random success/failure
      const success = Math.random() > 0.5;
  
      setTimeout(() => {
        if (success) {
          resolve(`Data for ID ${id}`);
        } else {
          reject(`Failed to fetch ID ${id}`);
        }
      }, 500);
    });
  }
  
  // Promise chain
  fetchData(1)
    .then((data) => {
      console.log(data);
      return fetchData(2);
    })
    .then((data) => {
      console.log(data);
      return fetchData(3);
    })
    .then((data) => {
      console.log(data);
      console.log("All fetches completed");
    })
    .catch((error) => {
      console.log("Error:", error);
    });
  
  /*
  Possible Output 1 (all succeed):
  Data for ID 1
  Data for ID 2
  Data for ID 3
  All fetches completed
  
  Possible Output 2 (second fails):
  Data for ID 1
  Error: Failed to fetch ID 2
  
  Possible Output 3 (first fails):
  Error: Failed to fetch ID 1
  
  Key insights:
  1. Promise chain stops at first rejection
  2. .catch handles ANY rejection in the chain
  3. Subsequent .then blocks are skipped after rejection
  4. Each run may have different outcomes due to randomness
  */

Exercise 3: Promise.race for Timeout Pattern

What to do: Use Promise.race with [fetchUser(7), wait(2000).then(() => Promise.reject(new Error("timeout")))] to add a 2-second timeout to a fetch.

// Helper functions
function wait(ms) {
  return new Promise((resolve) => {
    setTimeout(resolve, ms);
  });
}

// Fake fetch function with random delay
function fetchUser(id) {
  return new Promise((resolve) => {
    // Simulate random network delay (0-3 seconds)
    const delay = Math.random() * 3000;

    setTimeout(() => {
      resolve(`User ${id} loaded`);
    }, delay);
  });
}

// Promise.race with timeout
Promise.race([
  fetchUser(7),

  wait(2000).then(() => {
    return Promise.reject(new Error("timeout"));
  })
])
  .then((result) => {
    console.log("Success:", result);
  })
  .catch((error) => {
    console.log("Failed:", error.message);
  });

/*
Possible outcomes:

If fetchUser completes in < 2 seconds:
"Success: User 7 loaded"

If fetchUser takes > 2 seconds:
"Failed: timeout"

Key concepts:
1. Promise.race resolves/rejects with the FIRST settled promise
2. Timeout pattern: race actual operation vs timer
3. Either the operation succeeds quickly, or timeout wins
4. Used to prevent hanging on slow network requests
*/

Exercise 4: Promise.any for Resilient Fetching

What to do: Use Promise.any with three flaky fetches. Demonstrate that it returns the first SUCCESS, ignoring rejections.

// Flaky fetch function
function flakyFetch(name) {
    return new Promise((resolve, reject) => {
      // Random success/failure (50/50 chance)
      const success = Math.random() > 0.5;
  
      // Random delay (0-2 seconds)
      const delay = Math.random() * 2000;
  
      setTimeout(() => {
        if (success) {
          resolve(`${name} succeeded`);
        } else {
          reject(`${name} failed`);
        }
      }, delay);
    });
  }
  
  // Promise.any waits for first success
  Promise.any([
    flakyFetch("Fetch A"),
    flakyFetch("Fetch B"),
    flakyFetch("Fetch C")
  ])
    .then((result) => {
      console.log("First success:", result);
    })
    .catch((error) => {
      console.log("All failed:", error);
    });
  
  /*
  Possible Output 1:
  "First success: Fetch B succeeded"
  
  Possible Output 2:
  "First success: Fetch A succeeded"
  
  Possible Output 3 (rare - all fail):
  "All failed: [AggregateError]"
  
  Key insights:
  1. Promise.any ignores rejected promises
  2. Resolves with the FIRST successful promise
  3. Only rejects if ALL promises fail (AggregateError)
  4. Perfect for redundant operations (multiple servers, mirrors)
  5. Different from Promise.race (which takes first settled, success OR failure)
  */
