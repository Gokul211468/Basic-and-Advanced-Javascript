Exercise 1: Vehicle Inheritance Hierarchy

What to do: Build a Vehicle(brand) class with a start() method. Then build Car(brand, doors) and Bike(brand) that both extend it. Override start() in Car to call super.start() then log "Car-specific check". Test both.

// Parent class
class Vehicle {
    constructor(brand) {
      this.brand = brand;
    }
  
    start() {
      console.log(`${this.brand} vehicle started`);
    }
  }
  
  // Child class - Car
  class Car extends Vehicle {
    constructor(brand, doors) {
      super(brand);
      this.doors = doors;
    }
  
    start() {
      super.start();
      console.log("Car-specific check");
    }
  }
  
  // Child class - Bike
  class Bike extends Vehicle {
    constructor(brand) {
      super(brand);
    }
  }
  
  // Test Car
  const car = new Car("Toyota", 4);
  car.start();
  
  /*
  Output:
  Toyota vehicle started
  Car-specific check
  */
  
  // Test Bike
  const bike = new Bike("Yamaha");
  bike.start();
  
  /*
  Output:
  Yamaha vehicle started
  */

  /*
  Key inheritance concepts:
  1. extends creates prototype chain between classes
  2. super() calls parent constructor
  3. super.method() calls parent method (delegation)
  4. Child classes can override and extend parent behavior
  5. Bike inherits start() without modification
  */

Exercise 2: Counter with Static Tracking

What to do: Add a static count to your Counter class that tracks how many counters have been created. Increment in the constructor.

class Counter {
    // Static property
    static count = 0;
  
    // Private field
    #value = 0;
  
    constructor() {
      // Increment whenever a new object is created
      Counter.count++;
    }
  
    inc() {
      this.#value++;
    }
  
    dec() {
      if (this.#value === 0) {
        throw new Error("Count cannot go below 0");
      }
  
      this.#value--;
    }
  
    get value() {
      return this.#value;
    }
  }
  
  // Create counters
  const c1 = new Counter();
  const c2 = new Counter();
  const c3 = new Counter();
  
  // Check static count
  console.log(Counter.count); // 3
  
  // Use counters
  c1.inc();
  c1.inc();
  
  console.log(c1.value); // 2

  /*
  Static properties:
  1. Belong to the class itself, not instances
  2. Shared across all instances
  3. Accessed via ClassName.property
  4. Useful for tracking, configuration, utilities
  5. Each constructor call increments the shared counter
  */

Exercise 3: Temperature Class with Validation

What to do: Build a Temperature class with a private #celsius field and getters for celsius and fahrenheit. Add a setter for celsius that validates >= -273.15.

class Temperature {
    // Private field
    #celsius;
  
    constructor(celsius) {
      this.celsius = celsius; // uses setter
    }
  
    // Getter for celsius
    get celsius() {
      return this.#celsius;
    }
  
    // Setter with validation
    set celsius(value) {
      if (value < -273.15) {
        throw new Error(
          "Temperature cannot be below absolute zero"
        );
      }
  
      this.#celsius = value;
    }
  
    // Getter for fahrenheit
    get fahrenheit() {
      return (this.#celsius * 9) / 5 + 32;
    }
  }
  
  // Test
  const temp = new Temperature(25);
  
  console.log(temp.celsius);    // 25
  console.log(temp.fahrenheit); // 77
  
  // Update temperature
  temp.celsius = 100;
  
  console.log(temp.celsius);    // 100
  console.log(temp.fahrenheit); // 212
  
  // Invalid value
  try {
    temp.celsius = -300;
  } catch (e) {
    console.log(e.message);
    // "Temperature cannot be below absolute zero"
  }

  /*
  Advanced class features:
  1. Private fields (#celsius) - truly encapsulated
  2. Getter/setter pair - property-like access with validation
  3. Constructor using setter - validation runs on creation too
  4. Computed property (fahrenheit) - derived from private state
  5. Physics validation - absolute zero is the physical minimum
  */
