Day 22: Map and Set Collections

Hands-on: Guided Practice

Map and Set Exercises

Task 1: Map vs Object

What to do: Build a Map of products: "pen" → 50, "book" → 200, "bag" → 800. Iterate with for...of and log each as "item: ₹price". Use .has, .get, .delete, .size. Convert it to an Object with Object.fromEntries and back to a Map with new Map(Object.entries(...)).

// Creating and manipulating a Map
const products = new Map();

// Adding key-value pairs
products.set("pen", 50);
products.set("book", 200);
products.set("bag", 800);

// Iterating with for...of (preserves insertion order)
console.log("Product catalog:");
for (const [item, price] of products) {
    console.log(`${item}: ₹${price}`);
}
// Output:
// pen: ₹50
// book: ₹200
// bag: ₹800

// Map methods demonstration
console.log("Has pen?", products.has("pen"));        // true
console.log("Price of pen:", products.get("pen"));   // 50
products.delete("pen");
console.log("Size after deletion:", products.size);  // 2

// Object ↔ Map conversion
const obj = Object.fromEntries(products);
console.log("Converted to object:", obj);
// { book: 200, bag: 800 }

const mapAgain = new Map(Object.entries(obj));
console.log("Back to Map:", mapAgain);
// Map(2) { 'book' => 200, 'bag' => 800 }

Task 2: Deduplicate with Set

What to do: Take an array of student IDs with duplicates: [101, 102, 103, 101, 104, 102, 105]. Use a Set to deduplicate. Convert back to an array. Now compute the count of UNIQUE IDs. Try with mixed types [1, "1", 1, true, 1n] — predict and verify.

// Student IDs with duplicates
const ids = [101, 102, 103, 101, 104, 102, 105];

// Deduplicate using Set
const uniqueIds = [...new Set(ids)];
console.log("Unique student IDs:", uniqueIds);
// [101, 102, 103, 104, 105]

// Count unique IDs
console.log("Number of unique students:", uniqueIds.length);
// 5

// Mixed types demonstration
const mixed = [1, "1", 1, true, 1n];
console.log("Original mixed array:", mixed);

const uniqueMixed = [...new Set(mixed)];
console.log("Deduplicated mixed:", uniqueMixed);
// [1, "1", true, 1n]

console.log("Unique count:", uniqueMixed.length);
// 4

Task 3: Cache with Map

What to do: Write memoize(fn) — but this time use a Map instead of an object. Wrap an expensiveSquare(n) that logs "computing..." and returns n * n. Verify that calling it twice with 5 only logs "computing..." once. Then add a cache.size check.

// Memoization using Map (instead of Object)
function memoize(fn) {
    const cache = new Map();  // Map allows any type as key
    
    function memoized(arg) {
        // Check if result is already cached
        if (cache.has(arg)) {
            console.log(`Cache hit for ${arg}`);
            return cache.get(arg);
        }
        
        // Compute and store result
        console.log(`Computing result for ${arg}...`);
        const result = fn(arg);
        cache.set(arg, result);
        
        return result;
    }
    
    // Expose cache for debugging
    memoized.cache = cache;
    return memoized;
}

// Expensive function to memoize
function expensiveSquare(n) {
    console.log("  → Running expensive calculation...");
    return n * n;
}

// Create memoized version
const memoizedSquare = memoize(expensiveSquare);

// Test memoization
console.log("First call:");
console.log("Result:", memoizedSquare(5));

console.log("\nSecond call:");
console.log("Result:", memoizedSquare(5));

console.log("\nThird call with different input:");
console.log("Result:", memoizedSquare(7));

console.log("\nCache statistics:");
console.log("Cache size:", memoizedSquare.cache.size);
console.log("Cached keys:", [...memoizedSquare.cache.keys()]);

/*
Expected Output:
First call:
Computing result for 5...
  → Running expensive calculation...
Result: 25

Second call:
Cache hit for 5
Result: 25

Third call with different input:
Computing result for 7...
  → Running expensive calculation...
Result: 49

Cache statistics:
Cache size: 2
Cached keys: [5, 7]


*/

Bonus: WeakMap for Private Data

What to do: Use a WeakMap to store "metadata" for objects without modifying them. Build a tiny attach/get API: attach(obj, data) and get(obj). Test by attaching { lastClick: Date.now() } to two button objects. Drop one of the button references. Conceptually, the WeakMap entry will be GC'd.

// WeakMap for private metadata storage
const metadata = new WeakMap();

// API for attaching/retrieving metadata
function attach(obj, data) {
    metadata.set(obj, data);
    console.log("Metadata attached to object");
}

function get(obj) {
    return metadata.get(obj);
}

// Test objects (simulating DOM buttons)
let button1 = {
    id: "save-btn",
    text: "Save"
};

let button2 = {
    id: "cancel-btn", 
    text: "Cancel"
};

// Attach metadata without modifying the objects
attach(button1, {
    lastClick: Date.now(),
    clickCount: 3,
    disabled: false
});

attach(button2, {
    lastClick: Date.now() - 5000,
    clickCount: 1,
    disabled: true
});

// Retrieve metadata
console.log("Button 1 metadata:", get(button1));
console.log("Button 2 metadata:", get(button2));

// Demonstrate no direct modification
console.log("Button 1 original:", button1);
// Object remains unchanged - no metadata properties added

// Simulate button removal (memory cleanup)
console.log("Before nulling button1...");
button1 = null;  // Last reference dropped

// The WeakMap entry for the original button1 object
// will be garbage collected automatically
console.log("Button1 reference dropped - WeakMap entry will be GC'd");

// button2 metadata still accessible
console.log("Button 2 still has metadata:", get(button2));
